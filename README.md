# Phishing Email Investigation

A hands-on investigation of a real-world phishing email received in a personal inbox.

## What I did
- Analyzed email headers (SPF, DKIM, DMARC)
- Investigated the sending IP using AbuseIPDB
- Analyzed the malicious URL using urlscan.io
- Identified evasion techniques (fake Cloudflare check, abuse of Google Cloud Storage)
- Extracted IOCs and documented findings

## Tools used
Notepad, AbuseIPDB, VirusTotal, urlscan.io
